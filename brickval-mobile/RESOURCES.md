# UI Design for Vibe Coding — Resources

## Knowledge

- [Book: _Refactoring UI_ — Steve Schoger & Adam Wathan](https://www.refactoringui.com/)
  The single best resource for developers who want to design. Covers spacing, color, typography, shadows, and how to make UIs that don't look like Bootstrap. Use for: every lesson. Read the free preview at minimum.
- [shadcn/ui](https://ui.shadcn.com/)
  Beautifully designed, copy-paste React components built on Radix + Tailwind. The gold standard for "AI-friendly" UI — components the AI already knows. Use for: starting point for any new UI component.
- [Tailwind CSS Color Palette](https://tailwindcss.com/docs/customizing-colors)
  Pre-validated color scales that just work. Use for: never picking a bad color again.
- [Tailwind CSS Spacing Scale](https://tailwindcss.com/docs/customizing-spacing)
  0.25rem-based spacing system. Use for: everything — spacing is the #1 thing beginners get wrong.
- [Framer Motion Docs](https://www.framer.com/motion/)
  React animation library. Use for: animated reveals, micro-interactions, layout animations.
- [GSAP](https://gsap.com/docs/v3/)
  Pro-grade animation library (free tier is generous). Use for: scroll-triggered animations, complex timelines.
- [Google Fonts](https://fonts.google.com/)
  Free typefaces. Pair 1 display + 1 body. Use for: typography.
- [Fontsource](https://fontsource.org/)
  Self-host Google Fonts as npm packages — zero network requests. Use for: production font loading.
- [Easings.net](https://easings.net/)
  Visual reference for CSS cubic-bezier easing functions. Use for: animation feel.
- [Coolors](https://coolors.co/)
  Free color palette generator. Use for: exploring color schemes.
- [Aspect Ratio Calculator](https://www.design.com/ai-tools/aspect-ratio-calculator/) or similar
  Use for: calculating aspect ratios for hero sections and card art.

## Inspiration (Free)

- [Refero](https://refero.design/)
  Curated collection of beautiful real-world designs, searchable. Use for: reference images to prompt AI.
- [Awwwards](https://www.awwards.com/)
  Award-winning site designs. Use for: seeing what "great" looks like across industries.
- [Dribbble](https://dribbble.com/search/mobile-app)
  Search "mobile app" or "dashboard" for UI concepts. Use for: visual reference before coding.
- [Mobbin](https://mobbin.com/) (free tier limited)
  Screenshots of real apps. Use for: studying how apps like Notion, Linear, Cal.com handle spacing.

## Communities (Wisdom)

- [r/web_design](https://reddit.com/r/web_design)
  General design discussion. Use for: getting feedback on layouts.
- [r/Frontend](https://reddit.com/r/Frontend)
  Implementation-focused. Use for: animation and CSS technique questions.
- [Tailwind Labs Discord](https://tailwindcss.com/discord)
  Active community around Tailwind. Use for: Tailwind-specific UI questions.
- [shadcn/ui Discord](https://ui.shadcn.com/discord)
  Community around shadcn components. Use for: component patterns and examples.
