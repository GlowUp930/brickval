## Design Context

### Users
BrickVal is for LEGO collectors and resellers who need to scan a set quickly, confirm the set number, and get a trustworthy current USD market value.

### Brand Personality
The brand should feel premium, practical, and valuation-focused. It should give users confidence that the app is helping them make a clear buying, selling, or collection decision.

### Aesthetic Direction
Follow the `impeccable` design process for each design pass. Do not inherit legacy web-app constraints or hardcode a visual style before the design brief is shaped.

This file intentionally does not lock a palette, theme, layout style, typography system, or visual treatment. References, anti-references, color preferences, accessibility needs, and exact emotional direction should be discussed during the actual design pass.

### Design Principles
- Make the scan flow fast and native-mobile first.
- Keep navigation to three tabs only: Home, Scan, Settings.
- Use Home for a portfolio-tracker layout: value hero, compact stats, curved selected-horizon market history graph, timeline labels above the horizon selector, and ranked saved inventory.
- Treat both LEGO sets and minifigures as collectible inventory; the value chart reflects saved item market values over time, not purchase price.
- Keep Scan focused on capture and result reveal; the only mode complexity should be the Set/Minifig switch.
- Manual typed entry is for LEGO set numbers only. Minifigures should be camera-first because users do not have a simple app-facing minifigure ID to type.
- Make set vs minifigure scan mode visually obvious through distinct color treatment, not just label text.
- Make pricing confidence clear without overloading the user.
- Keep manual set number entry obvious when LEGO set camera scanning fails.
- Keep Home chart interactions smooth and touch-friendly: curved value line, dynamic tap tooltip that avoids the finger, and a visible date timeline above the horizon selector.
- Preserve the price reveal as the main emotional moment.
- Keep design decisions traceable to the confirmed `impeccable` design brief.
