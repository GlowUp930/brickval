UI Design Cheat Sheet

Print-friendly reference of the 5 levers. All values ready to copy-paste.

1. Spacing

Scale 4px increments (0.25rem) p-1=4px, p-2=8px, p-3=12px, p-4=16px, p-6=24px, p-8=32px
Card padding p-4 (16px) or p-6 (24px)
Section padding px-4 py-8 Horizontal: 16px, Vertical: 32px
Element gap (flex/grid) gap-2 (8px) or gap-3 (12px) or gap-4 (16px)
Page margins (mobile) px-4 (16px)

2. Color

Primary blue-600 (#2563eb)
Primary hover blue-700 (#1d4ed8)
Primary light blue-50 (#eff6ff) Use for alert/notification backgrounds
Text primary gray-900 (#111827) Not pure black!
Text secondary gray-500 (#6b7280)
Border gray-200 (#e5e7eb)
Surface hover gray-50 (#f9fafb)
Success green-600 (#16a34a)
Error red-600 (#dc2626)

3. Typography

Font Inter, system sans-serif
h1 text-3xl (30px) font-bold -tracking-[0.03em] Hero headings
h2 text-2xl (24px) font-semibold -tracking-[0.02em]
h3 text-xl (20px) font-semibold
Body text-base (16px) font-normal leading-6
Small / caption text-sm (14px) text-gray-500
Label / badge text-xs (12px) font-medium uppercase tracking-wider

4. Borders & Shadows

Border width 1px solid Never 2px+ for UI elements
Card border-radius rounded-xl (12px)
Button border-radius rounded-lg (8px)
Badge / pill radius rounded-full (9999px)
Input radius rounded-lg (8px)
Card shadow (default) shadow-sm (0 1px 2px rgba(0,0,0,0.05))
Card shadow (elevated) shadow-md (0 4px 12px rgba(0,0,0,0.08))
Modal / dropdown shadow-lg (0 10px 30px rgba(0,0,0,0.12))

5. Animation

Entrance (fade + slide) 300ms, ease-out, translateY(8px) → 0
Button press 100ms, scale 0.97 → 1
List stagger delay 50ms per item
Easing (entrances) cubic-bezier(0.16, 1, 0.3, 1)
Easing (transitions) cubic-bezier(0.4, 0, 0.2, 1)
Motion reduction @media (prefers-reduced-motion: reduce)

AI Prompt Template

Build a [component name] using Tailwind CSS with these design rules: - Spacing: Tailwind 4px scale, p-4/p-6 inside cards, gap-3 between elements - Colors: primary=blue-600, surface=white, text=gray-900, secondary=gray-500, border=gray-200, bg-hover=gray-50 - Typography: Inter font family, h1=text-3xl font-bold, h2=text-2xl font-semibold, body=text-base, caption=text-sm text-gray-500 - Borders: 1px solid gray-200, rounded-xl for cards, rounded-lg for buttons/inputs, rounded-full for badges - Shadows: shadow-sm default, shadow-md elevated - Animation: fade-up on entrance (animate-fade-up), scale on press (active:scale-95)
