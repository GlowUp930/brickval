# Mission: UI Design Level-Up for Vibe Coding

## Why
BrickVal needs to look as polished as Brickify and cal.ai — smooth animations, intentional spacing, premium feel. Right now the UI is functional but looks "default-ish." I want to know what specifically makes those sites look great and how to reproduce that look for free when coding with AI.

## Success looks like
- Ship a BrickVal screen that a designer couldn't immediately tell was AI-generated
- Know the 3–5 specific levers (spacing, color, type, shadows, animation) that make a UI feel polished
- Prompt an AI coder to produce a premium-looking component without hand-holding every CSS property
- Ship a Framer Motion animation that feels intentional, not tacked-on

## Constraints
- Free tools only (no paid design tools, no paid animation libraries beyond Framer Motion free tier)
- Must work with BrickVal's tech stack (React Native / Expo / Next.js / Tailwind)
- Learning time is limited — keep each lesson small and immediately applicable

## Out of scope
- Illustration or icon design (use existing assets)
- Brand identity creation
- Complex 3D or WebGL animations
